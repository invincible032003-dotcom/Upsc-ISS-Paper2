ISS STATISTICS PAPER II - OFFLINE MOCK EXAM PLATFORM
======================================================

WHAT THIS IS
------------
A 100% offline mock-exam platform built from all 720 authentic UPSC ISS
Statistics Paper II PYQs (2018-2026), classified by syllabus unit, topic
and subtopic (Linear Models / Statistical Inference and Hypothesis
Testing / Official Statistics).

Every question also carries an AI-derived Exam Shortcut, Tips & Tricks
and Step-by-Step Solution. The source booklets carry no official answer
key, so ALL explanatory content is independently derived and verified by
the builder of this platform, not copied from an official source. This
is clearly labelled "AI-derived explanation" throughout the app. A small
number of questions carry a "Source note" flagging a genuine ambiguity in
the original printed question/options - these are shown as-is, unaltered,
with the ambiguity explained rather than silently fixed.

HOW TO OPEN IT
---------------
1. Keep index.html, questions2.js, forecast.js and styles.css in the SAME
   folder.
2. Double-click index.html (or open it from your browser's File > Open).
3. That's it. No install, no internet connection, no server, no Python,
   no Node.js required. Works entirely from the local file.

PDF STUDY GUIDES (offline, in the PDFs/ folder)
--------------------------------------------------
Two print-ready PDFs, generated entirely offline from this same question
bank, for reading or printing without opening the app:

- Forecast-Linear-Models.pdf - every Linear Models forecast question,
  organised by topic, with all 4 options, the correct answer highlighted,
  and the Exam Shortcut shown openly beneath each question.
- Forecast-Statistical-Inference.pdf - the same, for the combined
  Estimation and Hypothesis Testing forecast bank.

Both carry the same "FORECAST / AI-GENERATED" notice as the app and are
meant as a portable answer-key companion to the Forecast Sectional Mocks
below, not a substitute for practising in the app itself.

MAIN MODES
----------
- Full Year Mocks: one authentic full-length mock per year (2018-2026),
  80 questions each, original order and options preserved, Strict Exam
  mode with a 2-hour timer - simulates the real paper.

- Sectional Mocks: practice one syllabus unit (Linear Models /
  Statistical Inference and Hypothesis Testing / Official Statistics)
  for a single year or across all years.

- Topic / Subtopic Mocks: drill down to a specific topic (e.g.
  "Analysis of Variance") or micro-topic (e.g. "Neyman-Pearson Lemma
  and Best Critical Region").

- Custom Mock Generator: pick any combination of years, units, topics
  and subtopics, choose how many questions, sequential or randomized
  order, and whether option order should be shuffled too.

- Practice My Mistakes: every question you get wrong is automatically
  added to a running mistake bank; practice just those.

- My Bookmarks: bookmark any question during an exam or review and
  revisit it later.

- Forecast Sectional Mocks: 661 AI-generated, examiner-style forecast
  questions for the next paper, organised into 25-question sets across
  three sections - Linear Models (11 sets), Estimation (11 sets) and
  Hypothesis Testing (6 sets). Set 1 of each section is a hand-authored
  starter set; every further set is drawn from a large evidence-based
  pattern-mining analysis of the 2018-2026 papers (archetype frequency,
  recycling intervals, due-date forecasting) or from a dedicated
  Statistical Inference practice bank covering estimation theory,
  sufficiency, CRLB, MLE/UMVUE, confidence intervals, Neyman-Pearson/UMP
  testing, LRT, SPRT and decision theory. Pick a section from the home
  screen to see all of its sets, or start the whole section as one mock.
  Every forecast question carries a bright "FORECAST / AI-GENERATED -
  NOT AN AUTHENTIC PYQ" banner and is kept in a completely separate
  question bank from the 720 real PYQs above - it is never mixed into a
  year, sectional, topic, or custom mock, and never counted in the main
  Analytics (which stays scoped to your real-PYQ performance). These
  mocks always run in Learning Mode, so the Exam Shortcut appears
  immediately after you answer each question.

- Analytics: accuracy broken down by unit, topic and question type,
  your weakest topics, a "Practice My Weak Areas" button, and a trend
  of your recent scores.

- Attempt History: every past attempt is saved locally, with the
  ability to reopen its full review.

STRICT EXAM MODE vs LEARNING MODE
----------------------------------
Strict Exam Mode hides the correct answer, explanations and shortcuts
until you submit - just like the real exam. It has a countdown timer
that auto-submits when time runs out, a question palette showing
answered/unanswered/marked-for-review status, and Previous/Next/Jump
navigation.

Learning Mode reveals feedback immediately after you answer, in this
fixed order and never any other order:
  1. Correct / Incorrect
  2. Exam Shortcut
  3. Tips & Tricks
  4. Step-by-Step Solution
Each stage is revealed one click at a time so you see the shortcut
before the full solution, matching how you should actually build
exam-day speed.

KEYBOARD SHORTCUTS (exam screen only, disabled while typing in a field)
-------------------------------------------------------------------------
  1 / 2 / 3 / 4   select option A / B / C / D
  Left arrow      previous question
  Right arrow     next question
  M               toggle mark for review

DARK MODE
-----------
The moon/sun button in the top bar toggles between light and dark
themes. Your choice is remembered on this device (also under an
"iss_p2_" key), so it stays set the next time you open the app. Until
you toggle it yourself, the app follows your device/browser's own
light-or-dark setting automatically. No internet connection or extra
files are needed - the whole theme is built into styles.css.

EXPORT / IMPORT / RESET PROGRESS
----------------------------------
Everything (attempt history, bookmarks, mistake bank, per-question
stats) is stored only in this browser's local storage, under keys
prefixed "iss_p2_" so it never collides with a separate Paper I mock
platform if both are used on the same device.

- Export (top bar): downloads a single JSON file with all of your
  local progress. Keep it as a backup or move it to another device.
- Import (top bar): choose a previously exported JSON file to restore
  or merge that progress back in.
- Reset (top bar): permanently clears all locally stored progress on
  this device/browser after you confirm. This cannot be undone.

NOTES ON THE MATHEMATICS
--------------------------
Formulas are rendered using a small built-in math renderer (fractions,
Greek letters, subscripts/superscripts, summations, square roots,
matrices, piecewise "cases" expressions, etc.) written specifically for
this dataset - there is no dependency on MathJax, KaTeX or any other
online rendering service, so equations remain fully readable offline.

DEVICE SUPPORT
---------------
Designed mobile-first for tablets (e.g. Samsung Galaxy Tab A9), iPad/
iOS Safari, and desktop/laptop browsers, in both portrait and landscape
orientation, with large touch targets and no horizontal scrolling.

NO SERVER, NO CLOUD, NO ACCOUNT
----------------------------------
This app never makes a network request. There is no login, no account,
no tracking, and no data ever leaves your device.
